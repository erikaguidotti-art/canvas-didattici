# Canvas Didattici

Raccolta di laboratori e strumenti interattivi creati per la didattica.

## 🎵 AcoustiLab DAW - Laboratorio di Fisica del Suono
Applicazione web interattiva per lo studio visivo e uditivo dell'acustica e della fisica delle onde:
- Generatore di oscillazioni e forme d'onda (sinusoidale, quadra, triangolare, dente di sega)
- Controllo in tempo reale di frequenza, ampiezza e fase
- Sovrapposizione di onde, battimenti e spettro sonoro
